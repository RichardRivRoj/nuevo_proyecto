# nuevo_proyecto
### Proyecto de prueba para el curso de Git y GitHub

- Este proyecto es una demostración de cómo usar Git y GitHub para el control de versiones y la colaboración en proyectos de software.
- El objetivo es aprender a crear repositorios, hacer commits, ramas, pull requests y gestionar el código de manera eficiente.

1. **Creación del repositorio**: Se creó un nuevo repositorio en GitHub llamado "nuevo_proyecto" para alojar el código y la documentación del proyecto.
2. **Estructura del proyecto**: Se organizó el *proyecto* en carpetas y archivos para mantener el código limpio y fácil de navegar.
